# วิธีใช้งานระบบหลังบ้าน (admin.html) สำหรับครู

เว็บไซต์นี้เชื่อมต่อกับ **Firebase Firestore** (ฐานข้อมูลออนไลน์ฟรีของ Google) แล้ว
ครูแก้ข้อมูลผ่านหน้า `admin.html` → **บันทึกขึ้นเว็บจริงให้อัตโนมัติทันที** ไม่ต้องดาวน์โหลด/อัปโหลดไฟล์อีกต่อไป
ทุกคนที่เข้าเว็บไซต์จะเห็นข้อมูลใหม่ทันทีที่รีเฟรชหน้า

## ขั้นตอนที่ 1: เปิดระบบหลังบ้าน

1. เปิดเว็บไซต์ (ผ่าน Live Server ตอนพัฒนา หรือ URL จริงบน GitHub Pages หลังเผยแพร่แล้ว)
2. คลิกไอคอนกุญแจเล็ก ๆ 🔒 มุมล่างของหน้าเว็บ (ในแถบท้ายเว็บไซต์) เพื่อไปที่ `admin.html`
3. กรอกรหัสผ่าน (ค่าเริ่มต้นคือ `korat2569` — **แนะนำให้เปลี่ยน** โดยเปิดไฟล์ `admin.html` ด้วย VS Code
   ค้นหาคำว่า `ADMIN_PIN` แล้วแก้ข้อความในเครื่องหมายคำพูดเป็นรหัสที่ต้องการ — ทำครั้งเดียวจบ)

> ⚠️ รหัสผ่านนี้กันแค่คนทั่วไปเข้ามาแก้โดยไม่ตั้งใจ ไม่ใช่ระบบความปลอดภัยระดับสูง เพราะกฎความปลอดภัยของฐานข้อมูล
> เปิดให้เขียนข้อมูลได้แบบไม่ต้องล็อกอินจริงจัง (ดูขั้นตอนที่ 3) — **อย่าใส่ข้อมูลที่เป็นความลับผ่านหน้านี้**

## ขั้นตอนที่ 2: แก้ไขข้อมูล

หน้า admin แบ่งเป็น 5 แท็บ — **ข้อมูลทั่วไป** (เบอร์โทร ที่อยู่ อีเมล โซเชียลมีเดีย โลโก้ ข้อความหน้าแรก
วิสัยทัศน์ พันธกิจ ประวัติโรงเรียน ฯลฯ), **ข่าวประชาสัมพันธ์**, **กิจกรรม**, **ประกาศหน้าแรก**, **บุคลากร**
(เพิ่ม/ลบ/แก้ไขได้ พร้อมแนบรูปภาพในข่าว/กิจกรรม/บุคลากรได้ด้วย — ระบบย่อ/บีบอัดรูปให้อัตโนมัติ)

ข่าวมีช่อง "เนื้อหาเต็ม" แยกจาก "รายละเอียดย่อ" (ไม่บังคับ) และบุคลากรมีช่อง "รายละเอียดเพิ่มเติม" (ไม่บังคับ)
สำหรับแสดงตอนมีคนกดดูรายละเอียดเต็มบนเว็บไซต์

พิมพ์แก้ในช่องได้เลย ระบบจะบันทึกขึ้นฐานข้อมูลให้เองภายในไม่ถึง 1 วินาทีหลังพิมพ์เสร็จ
ดูสถานะได้ที่แถบล่างสุดของหน้า: 🟡 กำลังบันทึก... / 🟢 บันทึกขึ้นเว็บแล้ว / 🔴 บันทึกไม่สำเร็จ

ปุ่ม **"🔄 ซิงก์ข้อมูลล่าสุด"** ใช้เมื่อมีครูอีกคนแก้ข้อมูลพร้อมกันในเครื่องอื่น
ปุ่ม **"⬇️ ดาวน์โหลดสำรอง (data.json)"** ใช้เก็บสำเนาข้อมูลปัจจุบันไว้ในเครื่อง ไม่จำเป็นต้องใช้ในการทำงานปกติ

## ขั้นตอนที่ 3: ตั้งกฎความปลอดภัยของฐานข้อมูล (Firestore Rules)

> ⚠️ **ถ้าก่อนหน้านี้เคยตั้งค่า Firebase Authentication (ล็อกอินด้วยอีเมล) ไว้ ต้องเปลี่ยนกฎกลับเป็นแบบนี้**
> ไม่งั้นจะบันทึกข้อมูลจาก admin.html ไม่ได้เลย เพราะไม่มีระบบล็อกอินจริงให้ตรวจสอบสิทธิ์อีกแล้ว

1. ไปที่ [Firebase Console](https://console.firebase.google.com) → เลือกโปรเจกต์ → เมนูซ้าย **Firestore Database** → แท็บ **Rules**
2. ลบข้อความเดิมทั้งหมด แล้ววางกฎนี้แทน:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read: if true;
      allow write: if true;
    }
  }
}
```

3. กด **Publish**

> หมายเหตุด้านความปลอดภัย: กฎนี้เปิดให้ใครก็ตามที่รู้ที่อยู่ฐานข้อมูล (projectId) เขียนข้อมูลได้โดยตรง ไม่ผ่านหน้า admin.html เลยก็ได้
> เหมาะกับเว็บไซต์ข้อมูลทั่วไปของโรงเรียนที่ไม่มีข้อมูลอ่อนไหว

## ขอบเขตของระบบนี้ (ยังไม่ครอบคลุม)

ส่วนต่อไปนี้ยังต้องแก้ในไฟล์ HTML โดยตรงเหมือนเดิม:
- หน้า "สำหรับนักเรียน" (ตารางเรียน/สอบ, ลิงก์ระบบออนไลน์)
- หน้า "ดาวน์โหลดเอกสาร" (รายการไฟล์)
- ชื่อโรงเรียน สีธีมเว็บไซต์
- ฟอร์มติดต่อ (ยังเป็นฟอร์มตัวอย่าง ไม่ส่งอีเมลจริง)

หากต้องการให้ส่วนไหนแก้ผ่านระบบหลังบ้านได้เพิ่มเติม แจ้งได้เลย
