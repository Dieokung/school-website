# วิธีใช้งานระบบหลังบ้าน (admin.html) สำหรับครู

เว็บไซต์นี้เชื่อมต่อกับ **Firebase** (ฐานข้อมูล Firestore + ระบบล็อกอิน Authentication) แล้ว
ครูแก้ข้อมูลผ่านหน้า `admin.html` → **บันทึกขึ้นเว็บจริงให้อัตโนมัติทันที** ไม่ต้องดาวน์โหลด/อัปโหลดไฟล์อีกต่อไป
และต้อง **ล็อกอินด้วยอีเมล-รหัสผ่านจริง** ถึงจะแก้ข้อมูลได้ (ไม่ใช่รหัส PIN แบบเดิมอีกต่อไป)

## ขั้นตอนที่ 1 (ทำครั้งเดียว): เปิดใช้งานระบบล็อกอิน + เพิ่มบัญชีครู

1. ไปที่ [Firebase Console](https://console.firebase.google.com) → เลือกโปรเจกต์ `korat-school-website`
2. เมนูซ้าย → **Build > Authentication** → กด **Get started**
3. แท็บ **Sign-in method** → เลือก **Email/Password** → เปิดใช้งาน (Enable) → Save
4. แท็บ **Users** → กด **Add user** → กรอกอีเมลและรหัสผ่านของครูที่จะใช้เข้าระบบหลังบ้าน → Add
   (เพิ่มได้หลายคน ทำซ้ำขั้นตอนนี้ทีละคน)

## ขั้นตอนที่ 2 (ทำครั้งเดียว): อัปเดตกฎความปลอดภัยของฐานข้อมูล

ไปที่ **Firestore Database → แท็บ Rules** แล้วแทนที่กฎเดิมด้วยอันนี้ (เข้มขึ้นกว่าเดิม — ตอนนี้ต้องล็อกอินก่อนถึงจะแก้ข้อมูลได้):

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read: if true;
      allow write: if request.auth != null;
    }
  }
}
```

กด **Publish** — ตั้งแค่ครั้งเดียว ไม่ต้องทำซ้ำ

## ขั้นตอนที่ 3: เข้าใช้งานระบบหลังบ้าน

1. คลิกไอคอนกุญแจเล็ก ๆ 🔒 มุมท้ายหน้าเว็บ เพื่อไปที่ `admin.html`
2. กรอก **อีเมลและรหัสผ่าน** ที่เพิ่มไว้ในขั้นตอนที่ 1 → เข้าสู่ระบบ
3. ระบบจะจำการล็อกอินไว้ให้ (ปิด-เปิดเบราว์เซอร์ใหม่ก็ยังล็อกอินค้างอยู่) จนกว่าจะกด **"ออกจากระบบ"** เอง

ถ้าลืมรหัสผ่าน หรืออยากลบสิทธิ์ครูคนใดคนหนึ่ง ผู้ดูแลไปจัดการได้ที่ Firebase Console → Authentication → Users
(กดรีเซ็ตรหัสผ่าน หรือลบบัญชีได้เลย)

## ขั้นตอนที่ 4: แก้ไขข้อมูล

หน้า admin แบ่งเป็น 5 แท็บ — **ข้อมูลทั่วไป** (เบอร์โทร ที่อยู่ อีเมล โซเชียลมีเดีย โลโก้ ข้อความหน้าแรก
วิสัยทัศน์ พันธกิจ ประวัติโรงเรียน ฯลฯ), **ข่าวประชาสัมพันธ์**, **กิจกรรม**, **ประกาศหน้าแรก**, **บุคลากร**
(เพิ่ม/ลบ/แก้ไขได้ พร้อมแนบรูปภาพในข่าว/กิจกรรม/บุคลากรได้ด้วย — ระบบย่อ/บีบอัดรูปให้อัตโนมัติ)

พิมพ์แก้ในช่องได้เลย ระบบจะบันทึกขึ้นฐานข้อมูลให้เองภายในไม่ถึง 1 วินาทีหลังพิมพ์เสร็จ
ดูสถานะได้ที่แถบล่างสุดของหน้า: 🟡 กำลังบันทึก... / 🟢 บันทึกขึ้นเว็บแล้ว / 🔴 บันทึกไม่สำเร็จ

ปุ่ม **"🔄 ซิงก์ข้อมูลล่าสุด"** ใช้เมื่อมีครูอีกคนแก้ข้อมูลพร้อมกันในเครื่องอื่น
ปุ่ม **"⬇️ ดาวน์โหลดสำรอง (data.json)"** ใช้เก็บสำเนาข้อมูลปัจจุบันไว้ในเครื่อง ไม่จำเป็นต้องใช้ในการทำงานปกติ

## ขอบเขตของระบบนี้ (ยังไม่ครอบคลุม)

ส่วนต่อไปนี้ยังต้องแก้ในไฟล์ HTML โดยตรงเหมือนเดิม:
- หน้า "สำหรับนักเรียน" (ตารางเรียน/สอบ, ลิงก์ระบบออนไลน์)
- หน้า "ดาวน์โหลดเอกสาร" (รายการไฟล์)
- ชื่อโรงเรียน สีธีมเว็บไซต์
- ฟอร์มติดต่อ (ยังเป็นฟอร์มตัวอย่าง ไม่ส่งอีเมลจริง)

หากต้องการให้ส่วนไหนแก้ผ่านระบบหลังบ้านได้เพิ่มเติม แจ้งได้เลย
